# Jungwoo Lee — Portfolio

Personal portfolio website. Two modes: Founder & Creator.

Built with Next.js 14, Tailwind CSS, Framer Motion, deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All content is hardcoded — edit `lib/content.ts` for shared data, or individual components in `components/founder/` and `components/creator/`.

Replace `public/images/hero.jpg` with your photo.

## Deploy

Push to GitHub and import the repo in [Vercel](https://vercel.com). No env vars required.
